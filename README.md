Aplicación web que genera visuales abstractos en 3D que reaccionan al ritmo, la frecuencia y la amplitud de una pista de audio o del micrófono en tiempo real.

## Tecnologías
TypeScript · WebGPU · Vite

## Cómo ejecutarlo
```bash
npm install
npm run dev
```
Requiere un navegador con soporte de WebGPU (Chrome o Edge recientes).

## Funcionalidades
- Cargar una pista de audio arrastrándola a la página, o usar el micrófono.
- Visuales 3D que reaccionan al ritmo, la frecuencia y la amplitud.
- Exportar el resultado como vídeo o imagen de alta resolución.
